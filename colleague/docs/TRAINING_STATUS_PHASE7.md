# a7 实机与多轮工具轨迹历史验收

本文记录 a7 阶段的历史本机验收，不代表当前公开提交已重复运行真实模型；逐项证据保存在本地，报告和真实日志不随源码公开。该阶段未发布公网、未改全局客户端配置、未自动开启真实项目采集。

实现：canonical v4保存整条实际多请求episode；严格函数调用/结果闭环、并行反序结果、错误后新调用ID重试；完整上下文与来源摘要校验；默认关闭及在途撤回；内容审核和中间步骤审核分离；标准prompt/completion JSONL、负评重复样本隔离、整组训练/评估划分、离线审计。

分组划分：按session关联完整episode，固定 `nous-phase7` 种子将12条目标分为10条train与2条eval，来源组无交叉，原始行字节不变；未评价模型泛化效果。

合成端到端：两平台10条episode，12条SFT、4条拒绝记录、0验证错误。真实TRL训练装载12条样本完成2步优化，提示词和工具结果损失被屏蔽，最大1151 tokens、无截断。使用随机小模型，不涉及预训练权重、模型效果测评或真实用户数据。

真实模型：Codex完成固定lookup并得到预期答案，手动导入1条候选、0条严格SFT；原生日志上下文缺失使严格导出拒绝，这是保护措施，不能据此宣布生产兼容完成。Claude真实模型尝试失败，CLI 文本曾被归为 budget_or_quota；该关键词分类不足以证明额度不足，未继续重试。只拿到工具目录不算执行工具成功。

本地脚本提供商实机：真实CLI、真实stdio MCP工具调用、固定错误与重试，provider响应由本地fixture脚本给出，不是模型推理。Claude Code与Codex均通过：每端3次请求/响应、2次实际MCP调用（1次错误、1次成功），3步完整canonical4；每端1条候选、0条SFT、1条拒绝记录、0验证错误。没有自动内容/步骤审核。实际报告见release/acceptance内对应JSON。原始请求/输出不写入报告；只保存静态诊断及通过采集器脱敏的候选。

仍属macOS开发者alpha。支持的严格函数工具子集、上下文固定要求、未知字段/隐式状态/隐藏推理/媒体拒绝、采集进程中断丢失在途episode等边界见 TRAINING_EPISODE.md、TRAINING_EPISODE_CAPTURE.md、TRAINING_MULTITURN_LIVE.md。
