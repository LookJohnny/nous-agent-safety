# 历史轨迹回溯导入（a8）

历史导入和实时监测是两个独立入口。即使此前没有安装hook，仍可读取平台已保留的本地日志；不会恢复已删除且无备份的数据，也不会补造原日志未记录的请求、工具定义、隐藏推理或结果。全部处理在本机，无上传、无模型调用，不修改原日志或全局客户端配置。

```bash
python3 hooks/nous_training.py history-scan --out /绝对路径/新的历史计划.json
python3 hooks/nous_training.py history-import --plan /绝对路径/新的历史计划.json --out /绝对路径/新的导入结果目录
```

默认覆盖 `CODEX_HOME/sessions`、`CODEX_HOME/archived_sessions`（缺省 `~/.codex`），以及 `CLAUDE_CONFIG_DIR/projects`（缺省 `~/.claude`），包含子代理目录。可用 `--agent claude|codex`，或重复传 `--project 原项目绝对路径` 限定范围。目录名和文件名不用于猜测会话身份。

扫描只读有界元数据。计划包含私有源路径、原项目路径、会话标识和文件stat签名，权限0600，请勿作为公开报告分享。摘要检查仅防止意外变化，不认证计划作者；只导入自己审阅过的本地计划。默认最多10000个来源，超过上限明确报告扫描未完成，不会默默称全部成功。

支持JSONL；Python 3.14自带 `compression.zstd` 时支持 `.jsonl.zst`，低版本没有该标准库时将压缩文件明确计为不支持。无外部解压命令、第三方下载或原始正文临时文件。原文件与解压后内容各限128MiB，单行8MiB、100万行、压缩窗口128MiB、最多10000帧；拒绝损坏/截断压缩帧和越界扩展。符号链接、特殊文件或读取期间改变的文件被拒绝。原压缩字节摘要和展开JSONL摘要分别保存。

导入会用同一个不可变内存快照校验全文身份、解析、脱敏并计算摘要。项目/会话冲突、未知身份或损坏内容会单独列出，不套用当前项目。分页继承、分支、子代理、缺父链等缺口绑定到候选质量，不拼接猜测历史。

原工作目录仍可核实时，沿用现有transcript候选解析；没有变成请求级或episode级完整数据。目录已搬走、删除或不可核实时，保留可见对话和工具调用结构，所有工具输入/输出正文在脱敏前移除，不访问原文件操作数或Git；明确标记工作区及请求上下文缺失。CodeMode只保留能解析的可见投影并注明原生协议不可恢复。这能回溯已有交流，但不能承诺完整保留当年的工具内容。

每个物理来源单独记录，子代理不会因为共享session ID覆盖父会话。同一家族使用分组标识避免误拆。重复导入已有来源不覆盖旧记录、不删除审核、不重新授权被撤回的数据；源文件变化返回 `source_changed_existing`，原有候选仍保留，更新需另行显式处理。已移至archive或另外压缩的物理副本可能各自形成候选，原生家族和内容去重仍由严格导出/分组校验处理，不混称不同任务。

采集缓存保存在 `NOUS_HOME/training/records`（缺省 `~/.nous-colleague`）。只为本次新记录添加一次性导入权限，保留项目原有实时capture/export开关。批次开始冻结撤回版本，过程中撤回或改变数据根会阻止后续写入及发布；中断后可用新输出目录重跑，已保存来源会跳过。

结果目录含 `report.json`、私有 `plan.json`，以及按profile区分的 `trl/`、`codemode-events-v1/`。其中 `trajectories.jsonl` 是脱敏候选；`sft.jsonl` 只容纳通过结构、质量及已有审核规则的样本。本批新历史记录不自动添加审核或成功证据，因此不能把候选数量当作可训练数量。报告只含计数、哈希、静态错误码，不含会话正文。

`processing_complete` 表示该计划已处理，`all_sources_imported` 表示无发现/处理缺口；二者均不证明原始模型请求完整。`full_model_request_context_recovered` 固定为false。CLI导入有缺口返回2，失败返回1；请查看具体原因而非仅判断退出码。
